# AS450-astroinformatica

Apuntes para el curso de Astroinformatica (FCFM U. de Chile)


### Reproducibilidad

Para crear y utilizar un ambiente de Python con las dependencias correctasse recomienda instalar Python 3 y utilizar los siguientes comandos (en linux/mac):

```bash
(venv) $ deactivate
$ python3 -m venv venv/
$ source venv/bin/activate
(venv) $ python -m pip install -r requirements.txt
```

Para más información, incluyendo la versión equivalente a los comandos anteriores para Windows, recomiendo leer: [Python Virtual Environments: A Primer](https://realpython.com/python-virtual-environments-a-primer)
